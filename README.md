# JS PVT. LTD.
JS PVT LTD is a comprehensive Fullstack Java application designed for modern organizations. It seamlessly integrates an E-commerce storefront, a Course Marketplace, and an Internship Management System into a single platform. The system features a powerful Admin Dashboard for total organizational control and a user-friendly interface for students and customers.
